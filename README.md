# croco-editor

Windows 用の Markdown 下書きエディタ。ライブプレビューと字数カウント（記法を
除いた実字数）が主目的。C#（WinForms）＋ WebView2 の殻に、CodeMirror 6 と
markdown-it のフロントエンドを載せている。

## インストール

ビルドせずに使うだけなら、[Releases](https://github.com/noileg/croco-editor/releases)
から `croco-editor-setup-*.exe` をダウンロードして実行するだけでよい（管理者
権限不要、ユーザーごとのインストール）。ファイルの関連付けはインストーラの
チェックボックスで選べる。ソースからビルドする場合は下記を参照。

## 構成

```
csharp/    C# 殻（host.cs）。Windows 同梱の csc.exe でビルド、.NET SDK 不要
csharp/vendor/  WebView2 の再頒布 DLL（同梱、NuGet 不要）
src/       webview 側 UI（編集＝CodeMirror 6、プレビュー＝markdown-it、
           字数カウント・下線トグル・docx/html 変換など）
dist/      フロントのビルド成果物（コミット済み。npm install 無しでも動く）
test/      回帰テスト
```

## ビルドと実行

```
npm install
node csharp/build_host.mjs
csharp/out/croco-editor.exe [ファイルパス]
```

`npm install` を省いても `node csharp/build_host.mjs` は通る（コミット済みの
`dist/` をそのまま使う）。フロントを編集したときだけ `npm install` が要る。

## 使い方

### ファイル

- 開く：Ctrl+O、または引数でファイルパスを渡す。同じファイルを開くと既存
  タブに切り替わる（未編集なら最新の中身に差し替える）
- 保存：Ctrl+S。編集停止 600ms で自動保存も効く（パスのあるタブのみ）
- 名前を付けて保存：Ctrl+Shift+S
- 形式を変換して保存：Markdown ⇔ .docx / .html への書き出し（メニューのみ）
- 印刷：Ctrl+Shift+P（プレビュー欄だけを印刷）
- タブを閉じる：Ctrl+W　終了：メニューから
- 新しいウィンドウ：Ctrl+Shift+N（`--new` 付きで起動すると単一インスタンス
  に参加しない独立ウィンドウになる）
- 外部でファイルが変わった場合：開いたままの未編集タブは自動で最新に
  追従する。編集中に外部でも変わった場合は保存のたびに「上書き／外部を
  読み込む／保留」を選べる

### タブ

- 複数ファイルを同時に開いて切り替え（タブごとに Undo 履歴・スクロール
  位置・字数設定が独立）
- 切り替え：Ctrl+Tab（次）／Ctrl+Shift+Tab（前）／Ctrl+PageDown・PageUp
- 閉じる：タブの × クリック、または中クリック
- `.json` / `.tasks` / `README.md` は独立したウィンドウで開く

### 編集

- 元に戻す／やり直し：Ctrl+Z／Ctrl+Y
- 切り取り／コピー／貼り付け／すべて選択：Ctrl+X／C／V／A
- 検索：Ctrl+F　次・前を検索：F3／Shift+F3　置換：Ctrl+H　行へ移動：Ctrl+G
- 日付と時刻を挿入：メニューから（`YYYY-MM-DD HH:MM`）
- 編集欄の右クリックで同等の操作をまとめたメニューも出る
- 中ボタンドラッグでスクロール（エディタ／プレビュー／メモ欄）

### 下線・エスケープ記法

- 下線 `<u>…</u>`：Ctrl+U（選択範囲に付け外しをトグル）
- 二重下線 `<uu>…</uu>`：Ctrl+Shift+U
- 選択範囲に一括で下線（すでに下線が引いてある部分は除く）：メニューから
- エスケープ `<esc>…</esc>`：Ctrl+E。この範囲はプレビューにも字数カウント
  にも含まれない（下書き段階のメモやコメントを本文と一緒に置いておくのに使う）

### 字数カウント

- 上限：ツールバーの数値入力、または `400`/`600`/`800`/`1000`/`1200`/
  `1600`/`2000` のプリセットボタン
- 「空白も数える」「記法を数えない」のチェックボックスで数え方を切り替え
- 上限を超えた範囲はエディタ上で背景色が付く
- ステータスバーに現在の字数・行列位置・（選択中なら選択字数）・フォント
  サイズ・ファイルパスを常時表示

### プレビュー

- 表示切替：Ctrl+P
- エディタと連動してスクロール
- `<u>`/`<uu>`/`<ublock>`/`<qblock>`/`<esc>` を解釈して表示。表は通常の
  Markdown テーブル
- プレビュー内のリンク：外部 URL は既定ブラウザ、相対パスは同じフォルダの
  ファイルとして新しいタブで開く

### 表示

- 拡大／縮小／既定サイズ：Ctrl++／Ctrl+-／Ctrl+0（Ctrl+ホイールでも可）
- 右端で折り返す：メニューのチェックで切替
- 書体：メニューから8種類（游ゴシック UI / メイリオ UI / メイリオ / MS ゴシック
  / 游明朝 / MS 明朝 / BIZ UDPゴシック / BIZ UDP明朝）
- エディタとプレビューの仕切りはドラッグで幅を調整できる

### メモ広場（Ctrl+M）

下書きファイルごとに対応する外部メモを表示するパネル。ノートの実体は
`%APPDATA%\croco-editor\claude_notes\` 以下に、下書きの絶対パスから計算した
ファイル名（SHA1 先頭16桁 `.md`）で置かれる。別プロセス（スクリプトや
Claude Code など）がそのファイルに書き込めば、開いたまま 1 秒以内に画面へ
反映される。

- 表示する／しない：Ctrl+M
- 編集する：メニューから切り替え（チェック中はテキストエリアで直接編集、
  離脱時に保存）
- ファイルを選択...：このタブに限り任意のメモファイルを手動で指定
- 自動対応に戻す：手動指定を解除し、下書きパスからの自動計算に戻す

### ファイル関連付け

`.md`/`.tasks` を既定プログラムに登録する：

```
python setup_association.py           # 登録
python setup_association.py --check   # 現状確認
python setup_association.py --remove  # 解除
```

## テスト

```
node test/check.mjs        # 字数カウント
node test/tags.check.mjs   # 下線トグル
node test/fmt.check.mjs    # docx/html 変換
```
