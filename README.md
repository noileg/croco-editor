# croco-editor

Windows 用の Markdown 下書きエディタ。ライブプレビューと字数カウント（記法を
除いた実字数）が主目的。C#（WinForms）＋ WebView2 の殻に、CodeMirror 6 と
markdown-it のフロントエンドを載せている。

## インストール

ビルドせずに使うだけなら、[Releases](https://github.com/noileg/croco-editor/releases)
から `croco-editor-setup-*.exe` をダウンロードして実行するだけでよい（管理者
権限不要、ユーザーごとのインストール）。ファイルの関連付けはインストーラの
チェックボックスで選べる。ソースからビルドする場合は下記を参照。

## 構成

```
csharp/    C# 殻（host.cs）。Windows 同梱の csc.exe でビルド、.NET SDK 不要
csharp/vendor/  WebView2 の再頒布 DLL（同梱、NuGet 不要）
src/       webview 側 UI（編集＝CodeMirror 6、プレビュー＝markdown-it、
           字数カウント・下線トグル・docx/html 変換など）
dist/      フロントのビルド成果物（コミット済み。npm install 無しでも動く）
test/      回帰テスト
```

## ビルドと実行

```
npm install
node csharp/build_host.mjs
csharp/out/croco-editor.exe [ファイルパス]
```

`npm install` を省いても `node csharp/build_host.mjs` は通る（コミット済みの
`dist/` をそのまま使う）。フロントを編集したときだけ `npm install` が要る。

## 使い方

### ファイル

ファイルを開くにはCtrl+Oを押すか、起動時の引数にパスを渡す。同じファイルをもう一度開いたときは、そのタブがまだ編集されていない限り、開き直した時点の最新の内容に差し替わる。保存はCtrl+Sだが、パスを持つタブは編集が止まって600msでも自動的に保存されるので、こまめに押さなくても困らない。別の場所へ保存し直したいときはCtrl+Shift+Sで名前を付けて保存する。Markdownと`.docx`・`.html`の間で形式を変換して保存したい場合は、メニューの「形式を変換して保存」から行う（この操作にショートカットはない）。印刷はCtrl+Shift+Pで、印刷されるのはプレビュー欄の内容だけである。タブを閉じるのはCtrl+W、アプリ自体を終了するのはメニューの「終了」から行う。

新しいウィンドウはCtrl+Shift+Nで開く。これは起動時に`--new`を付けたときと同じ扱いで、単一インスタンスの仕組みには参加しない独立したウィンドウになる（下記の「タブ」による一元管理からは外れる）。

開いたまま手をつけていないファイルが外部で書き換わった場合、croco-editorは自動でその変更を取り込み、画面を最新の内容に更新する。一方、自分でも編集している最中に外部でも変更が入っていた場合は、保存しようとするたびに「自分の内容で上書きする」「外部の内容を読み込む」「このまま保留する」のいずれかを選ぶダイアログが出る。

### タブ

複数のファイルを同時に開き、タブで切り替えながら編集できる。Undo履歴・スクロール位置・字数の上限設定はタブごとに独立しているので、あるタブでの操作が別のタブへ波及することはない。切り替えはCtrl+Tab（次のタブ）・Ctrl+Shift+Tab（前のタブ）のほか、Ctrl+PageDown・Ctrl+PageUpでも行える。閉じるときはタブの×をクリックするか、タブそのものを中クリックする。

なお`.json`・`.tasks`・`README.md`はこのタブの仕組みに乗らず、開くたびに独立したウィンドウになる。

### 編集

元に戻す・やり直しはCtrl+Z・Ctrl+Y、切り取り・コピー・貼り付け・すべて選択はCtrl+X・Ctrl+C・Ctrl+V・Ctrl+Aと、一般的なエディタと変わらない操作感になっている。検索はCtrl+Fで開き、F3・Shift+F3で次・前の候補へ移る。置換はCtrl+H、指定した行へ飛ぶのはCtrl+Gである。日付と時刻（`YYYY-MM-DD HH:MM`の形式）を挿入したいときは、メニューから呼び出す。

同じ操作は、編集欄を右クリックして出るメニューからも一通り行える。また、エディタ・プレビュー・メモ欄のどこであっても、中ボタンを押したままドラッグすればスクロールする。

### 下線・エスケープ記法

選択範囲に下線を引く、あるいは外すにはCtrl+Uを押す。トグル式なので、すでに下線が引かれている範囲を選んで押せば下線が外れる仕組みになっている。二重下線はCtrl+Shift+Uで同様に扱う。選択範囲全体にまとめて下線を引きたいとき（すでに引かれている部分はそのまま残る）は、メニューの「選択範囲に一括で下線」を使う。

Ctrl+Eで囲んだ範囲は`<esc>`タグになり、プレビューにも字数カウントにも数えられなくなる。本文の中に下書き段階のメモやコメントを残しておきたいときに使うための機能である。

### 字数カウント

字数の上限は、ツールバーの数値入力に直接打ち込むか、400・600・800・1000・1200・1600・2000のプリセットボタンから選ぶ。「空白も数える」「記法を数えない」のチェックボックスで数え方を切り替えられ、上限を超えた部分はエディタ上で背景色が付いて分かるようになっている。ステータスバーには、今の字数・カーソルの行と列（範囲を選択していればその字数も）・フォントサイズ・開いているファイルのパスが常に表示される。

### プレビュー

表示・非表示はCtrl+Pで切り替える。プレビューはエディタのスクロールに連動し、`<u>`・`<uu>`・`<ublock>`・`<qblock>`・`<esc>`を解釈して表示する。表は通常のMarkdownの表として描画される。プレビュー内のリンクは、外部URLであれば既定のブラウザで開き、相対パスであれば同じフォルダのファイルとして解決したうえで新しいタブで開く。

### 表示

拡大・縮小・既定サイズへ戻すのはCtrl++・Ctrl+-・Ctrl+0で、Ctrl+ホイールでも同じことができる。右端で折り返すかどうかはメニューのチェックで切り替わる。書体はメニューから、游ゴシックUI・メイリオUI・メイリオ・MSゴシック・游明朝・MS明朝・BIZ UDPゴシック・BIZ UDP明朝の8種類を選べる。エディタとプレビューの境目はドラッグすると幅を調整できる。

### メモ広場（Ctrl+M）

開いている下書きファイルに対応した外部メモを表示するパネルで、Ctrl+Mで表示・非表示を切り替える。メモの実体は`%APPDATA%\croco-editor\claude_notes\`以下に、下書きの絶対パスから計算したファイル名（SHA1の先頭16桁に`.md`を付けたもの）で置かれている。手元のスクリプトやClaude Codeなど、別のプロセスがこのファイルに書き込めば、croco-editorを開いたまま1秒以内に画面へ反映される。

メニューの「編集する」に切り替えると、パネルがテキストエリアになって直接編集できるようになり、そこから離れると自動で保存される。「ファイルを選択...」を使えば、そのタブに限って任意のメモファイルを手動で指定でき、「自動対応に戻す」を選べば手動指定を解除して下書きパスからの自動計算に戻る。

### ファイル関連付け

`.md`/`.tasks` を既定プログラムに登録する：

```
python setup_association.py           # 登録
python setup_association.py --check   # 現状確認
python setup_association.py --remove  # 解除
```

## テスト

```
node test/check.mjs        # 字数カウント
node test/tags.check.mjs   # 下線トグル
node test/fmt.check.mjs    # docx/html 変換
```
