# croco-editor

Windows 用の Markdown 下書きエディタ。ライブプレビューと字数カウント（記法を
除いた実字数）が主目的。C#（WinForms）＋ WebView2 の殻に、CodeMirror 6 と
markdown-it のフロントエンドを載せている。

## インストール

ビルドせずに使うだけなら、[Releases](https://github.com/noileg/croco-editor/releases)
から `croco-editor-setup-*.exe` をダウンロードして実行するだけでよい（管理者
権限不要、ユーザーごとのインストール）。ファイルの関連付けはインストーラの
チェックボックスで選べる。ソースからビルドする場合は下記を参照。

## 構成

```
csharp/    C# 殻（host.cs）。Windows 同梱の csc.exe でビルド、.NET SDK 不要
csharp/vendor/  WebView2 の再頒布 DLL（同梱、NuGet 不要）
src/       webview 側 UI（編集＝CodeMirror 6、プレビュー＝markdown-it、
           字数カウント・下線トグル・docx/html 変換など）
dist/      フロントのビルド成果物（コミット済み。npm install 無しでも動く）
test/      回帰テスト
```

## ビルドと実行

```
npm install
node csharp/build_host.mjs
csharp/out/croco-editor.exe [ファイルパス]
```

`npm install` を省いても `node csharp/build_host.mjs` は通る（コミット済みの
`dist/` をそのまま使う）。フロントを編集したときだけ `npm install` が要る。

## 使い方

### ファイル

- 開く：Ctrl+O、または起動時の引数にファイルパスを渡す。同じファイルがすでにタブで開いていれば、そのタブに切り替わる。まだ編集していないタブなら、そのとき読み直した最新の内容に差し替わる
- 保存：Ctrl+S。パスのあるタブは、編集を止めてから600ms経つと自動でも保存される
- 名前を付けて保存：Ctrl+Shift+S
- 形式を変換して保存：メニューから。Markdownと`.docx`・`.html`の間で変換して保存できる（ショートカットは無い）
- 印刷：Ctrl+Shift+P。印刷されるのはプレビュー欄だけ
- タブを閉じる：Ctrl+W
- 終了：メニューから
- 新しいウィンドウ：Ctrl+Shift+N。起動時に`--new`を付けたときと同じ扱いで、単一インスタンスの仕組みに参加しない独立したウィンドウになる
- 外部での変更への追従：開いたまま編集していないタブは、そのファイルが外部で書き換わると自動で最新の内容に更新される。逆に自分でも編集している最中に外部でも変更が入っていた場合は、保存しようとするたびに「自分の内容で上書きする」「外部の内容を読み込む」「そのまま保留する」のいずれかを選ぶダイアログが出る

### タブ

- 複数のファイルを同時に開いてタブで切り替えられる。Undo履歴・スクロール位置・字数の上限設定はタブごとに独立していて、あるタブでの操作が別のタブに影響することはない
- 切り替え：Ctrl+Tab（次のタブ）、Ctrl+Shift+Tab（前のタブ）。Ctrl+PageDown・Ctrl+PageUpでも同じように切り替えられる
- 閉じる：タブの×をクリックするか、タブそのものを中クリックする
- `.json`・`.tasks`・`README.md`はこのタブの仕組みには乗らず、開くたびに独立したウィンドウになる

### 編集

- 元に戻す／やり直し：Ctrl+Z／Ctrl+Y
- 切り取り／コピー／貼り付け／すべて選択：Ctrl+X／Ctrl+C／Ctrl+V／Ctrl+A
- 検索：Ctrl+F。次・前の候補への移動はF3・Shift+F3
- 置換：Ctrl+H
- 指定した行へ移動：Ctrl+G
- 日付と時刻の挿入：メニューから。`YYYY-MM-DD HH:MM`の形式で挿入される
- 右クリックメニュー：編集欄を右クリックすると、同じ操作をまとめたメニューが出る
- 中ボタンでのスクロール：エディタ・プレビュー・メモ欄のどこでも、中ボタンを押したままドラッグするとスクロールできる

### 下線・エスケープ記法

- 下線：Ctrl+U。選択範囲に対するトグルなので、すでに下線が引かれている範囲を選んで押すと下線が外れる
- 二重下線：Ctrl+Shift+U。下線と同じくトグルで切り替わる
- 一括で下線：メニューから。選択範囲全体に下線を引くが、すでに引かれている部分にはそのまま手を付けない
- エスケープ：Ctrl+E。`<esc>`で囲んだ範囲はプレビューにも字数カウントにも入らなくなるので、下書き段階のメモやコメントを本文の中に残しておきたいときに使う

### 字数カウント

- 上限の指定：ツールバーの数値入力に直接打ち込むか、400・600・800・1000・1200・1600・2000のプリセットボタンから選ぶ
- 数え方の切り替え：「空白も数える」「記法を数えない」のチェックボックスで切り替えられる
- 上限を超えた部分は、エディタ上で背景色が付いて分かるようになっている
- ステータスバーには、今の字数・カーソルの行と列（選択中はその字数も）・フォントサイズ・開いているファイルのパスが常に表示される

### プレビュー

- 表示・非表示の切り替え：Ctrl+P
- エディタのスクロールに連動して動く
- `<u>`・`<uu>`・`<ublock>`・`<qblock>`・`<esc>`を解釈して表示する。表は通常のMarkdownの表として描画される
- リンク：外部URLは既定のブラウザで開き、相対パスは同じフォルダのファイルとして解決したうえで新しいタブで開く

### 表示

- 拡大・縮小・既定サイズへ戻す：Ctrl++・Ctrl+-・Ctrl+0。Ctrl+ホイールでも同じことができる
- 右端で折り返すかどうかは、メニューのチェックで切り替わる
- 書体：メニューから8種類（游ゴシックUI・メイリオUI・メイリオ・MSゴシック・游明朝・MS明朝・BIZ UDPゴシック・BIZ UDP明朝）を選べる
- エディタとプレビューの境目はドラッグすると幅を調整できる

### メモ広場（Ctrl+M）

開いている下書きファイルに対応した外部メモを表示するパネル。表示・非表示はCtrl+Mで切り替える。

- 保存先：`%APPDATA%\croco-editor\claude_notes\`以下に、下書きの絶対パスから計算したファイル名（SHA1の先頭16桁に`.md`を付けたもの）で置かれる
- 外部からの反映：手元のスクリプトやClaude Codeなど、別のプロセスがこのファイルに書き込むと、croco-editorを開いたまま1秒以内に画面へ反映される
- 編集する：メニューから切り替える。切り替えるとパネルがテキストエリアになって直接編集でき、そこから離れると自動で保存される
- ファイルを選択...：このタブに限り、任意のメモファイルを手動で指定できる
- 自動対応に戻す：手動指定を解除し、下書きパスからの自動計算に戻す

### ファイル関連付け

`.md`/`.tasks` を既定プログラムに登録する：

```
python setup_association.py           # 登録
python setup_association.py --check   # 現状確認
python setup_association.py --remove  # 解除
```

## テスト

```
node test/check.mjs        # 字数カウント
node test/tags.check.mjs   # 下線トグル
node test/fmt.check.mjs    # docx/html 変換
```
